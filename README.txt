CLAPPY BIRD — DEPLOYMENT PACKAGE

The complete game is contained in index.html.

This package is ready for static hosting:
- GitHub Pages
- Netlify
- Vercel
- Any standard web host

No build command, npm install, or backend is required.

For GitHub Pages:
1. Create/open your repository.
2. Upload index.html (and optionally this README).
3. Enable Pages in Settings → Pages.
